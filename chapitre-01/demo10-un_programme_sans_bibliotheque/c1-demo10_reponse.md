Voici le code de sortie produit avec l'aide de la commande $LASTEXITCODE:
$LASTEXITCODE
7
La taille du fichier de cette dixième démonstration est de :
37 666 octets
Celle du fichier qui n'affiche que bonjour est de :
72 563 octets
 Dans le but d'afficher le retour du printf l'editeur des liens a ajouté les fonctions de base qui sont associées à la communication avec l'éran de l'ordinateur. Le code capable d'analyser le texte, de gérer les formats (comme convertir des nombres en texte si besoin) et de gérer les sauts de ligne (\n). C'est à cause de ces fonctions de base que la taille du fichier grimpe tant (de 37666 at 72563 octets). Si on venait à enlever le printf la taille du fichier serait 37 666 octets.
