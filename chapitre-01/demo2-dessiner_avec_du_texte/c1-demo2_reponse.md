Pour construis un rectangle borné par des "#" il m'a fallut 11 lignes de codes. En sachant que j'inclus la ligne de la bilbiothèque et celle de retour.
Voici le code et ce qu'il affiche:
#include <cstdio>
int main() {
    printf("####################\n");
    printf("#                  #\n");
    printf("#                  #\n");
    printf("#                  #\n");
    printf("#                  #\n");
    printf("#                  #\n");
    printf("####################\n");
}
 affichage:
####################
#                  #
#                  #
#                  #
#                  #
#                  #
####################
